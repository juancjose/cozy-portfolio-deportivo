# Cozy Sport — Portfolio (Diseño A · "Dark sport")

**Ver el sitio online:** [https://juancjose.github.io/cozy-portfolio-deportivo/](https://juancjose.github.io/cozy-portfolio-deportivo/)

Rediseño de https://cozysport.com/portfolio/ con estética oscura y deportiva.
Sitio estático (HTML + CSS + JS, sin build). Imágenes y logo originales de cozysport.com en `assets/`.

Ver local: `python3 -m http.server` y abrir http://localhost:8000
